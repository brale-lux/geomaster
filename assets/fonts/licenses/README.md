# Font licences

The style guide specifies Source Sans 3 (game-show theme), Fredoka and Nunito (playful theme).
All three are licensed under the SIL Open Font License 1.1, which permits bundling in commercial apps.
The licence texts here were taken from the google/fonts repository. Ship them with the app
(Flutter: register them with `LicenseRegistry`) when the font files are added in Phase B.
